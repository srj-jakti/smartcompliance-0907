# SmartCompliance — Design System

## Brand
- **Name**: SmartCompliance
- **Tagline**: Automate Smarter. Work Faster.
- **Target**: Chartered Accountants & Accounting Firms in India

## Colors
- **Primary Blue**: #1D4ED8 (Trust, professionalism)
- **Blue Dark**: #1E3A8A (Headers, nav)
- **Blue Light**: #EFF6FF (Backgrounds, cards)
- **Blue Mid**: #3B82F6 (Hover states, accents)
- **White**: #FFFFFF (Main background)
- **Slate Gray**: #64748B (Body text, secondary)
- **Dark Text**: #0F172A (Headings)
- **Border**: #E2E8F0
- **Success**: #10B981
- **Warning**: #F59E0B
- **Danger**: #EF4444

## Typography
- **Font**: Inter (Google Fonts)
- **Hero Heading**: 56px / 700 / tight letter-spacing
- **Section Heading**: 36px / 700
- **Card Title**: 20px / 600
- **Body**: 16px / 400 / #64748B
- **Small**: 14px / 400

## Spacing
- Section padding: py-20
- Card padding: p-6
- Gap between cards: gap-6
- Container max-width: 1280px

## Style
- Clean white background with blue accents
- Cards with subtle shadows (shadow-md) and rounded-xl corners
- Blue gradient buttons (from-blue-600 to-blue-700)
- Subtle blue-tinted section backgrounds (#EFF6FF)
- Professional, minimal, no clutter
- Icons from lucide-react throughout

## Components Pattern
- Navbar: white bg, blue logo, nav links, blue CTA button
- Hero: bold dark headline, blue highlighted word, subtitle, dual CTAs, dashboard preview screenshot
- Feature cards: white cards with blue icon, title, description
- Stats: large numbers in blue, label below
- Testimonials: card grid with avatar, name, company, stars
- Pricing: toggle monthly/annual, highlighted popular plan in blue
- FAQ: accordion style
- Footer: multi-column, blue links
